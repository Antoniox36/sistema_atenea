1. OBJETIVO DEL MODULO
----------------------------------------------------------------------
El modulo 'security' se encarga de proteger las credenciales del sistema,
garantizando que ninguna clave o contrasena sea procesada o almacenada
en texto plano. Implementa algoritmos de resumen criptografico (hash)
unidireccionales bajo estandares seguros de la industria.

3. FUNCIONES IMPLEMENTADAS (auth_manager.py)
----------------------------------------------------------------------

A) hashear_contrasena(contrasena: str) -> str
   - Descripcion:
     Toma una contrasena en texto plano y aplica el algoritmo criptografico
     SHA-256 para transformarla en un resumen (hash) hexadecimal de 64 caracteres.
   - Proceso interno:
     1. Codifica la cadena a bytes mediante UTF-8 (.encode('utf-8')).
     2. Pasa los bytes al algoritmo hashlib.sha256().
     3. Obtiene y retorna la cadena hexadecimal resultante (.hexdigest()).
   - Alias incluido:
     hash_password(contrasena)

B) verificar_credenciales(usuario: str, contrasena: str) -> bool
   - Descripcion:
     Verifica las credenciales ingresadas por un usuario contra la base de
     usuarios autorizados del sistema.
   - Proceso interno:
     1. Valida que el usuario y contrasena no sean nulos o vacios.
     2. Verifica si el usuario existe en el diccionario USUARIOS_AUTORIZADOS.
     3. Hashea la contrasena recibida con SHA-256.
     4. Utiliza 'hmac.compare_digest' para comparar el hash calculado con
        el hash esperado. Esto evita ataques basados en tiempo (timing attacks).
     5. Retorna True si coinciden las credenciales, o False si fallan.
   - Alias incluidos:
     verificar_login(usuario, contrasena)
     check_credentials(usuario, contrasena)

5. EJEMPLO DE INTEGRACION (Para controlador_login.py)
----------------------------------------------------------------------
Desde el controlador de Login (controllers/controlador_login.py), el
responsable (Pablo) puede consumir este modulo de la siguiente manera:

    from security.auth_manager import verificar_credenciales

    def procesar_login(self):
        usuario = self.ventana_login.usuario.text().strip()
        contrasena = self.ventana_login.contrasena.text().strip()

        if verificar_credenciales(usuario, contrasena):
            print("Acceso concedido.")
            self.iniciar_sesion()
        else:
            raise ValueError("Credenciales invalidas.")
